# news-image-20261123

One-day world news poster entry for make.fun's news-image-20261123 competition.
`main.py` draws a 1024x1024 PNG of the day's stories with PIL (stdlib + preinstalled PIL);
it falls back to copying the committed `entry.png` to /output if PIL is unavailable.
